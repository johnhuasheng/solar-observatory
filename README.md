# 星际漫游 · 太阳系观测站

一个可交互的太阳系三维观测网页，包含行星探索、自动巡航、科普资料和剖面图。网页在浏览器中运行，不需要自建后端服务。

## 在线体验

在线体验地址将在首次公开发布后补充。在线版与本地版相互独立；更新本地文件不会自动发布到网上。

## 本地使用

下载完整项目后，在 Windows 上双击 `启动观测站.cmd`。浏览器会打开本地版本，启动窗口随后自动关闭；后台服务可通过 `关闭观测站.cmd` 结束。若下载的是尚未包含 `网页/` 构建结果的源码包，请先按下方步骤构建。

## 从源码构建

需要 Node.js 22.13 或更新版本。在项目根目录运行：

```powershell
npm ci
npm run build
```

构建结果位于 `网页/`。Windows 用户也可以双击 `重新构建网页.cmd`。源码位于 `src/`，静态贴图等素材位于 `public/`。
